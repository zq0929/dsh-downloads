安装说明

macOS

  • 打开 dmg，把 DeepSeek Harness.app 拖进「应用程序」。
  • Apple Silicon 选 macos-arm64，Intel 选 macos-x64。
  • 包是 ad-hoc 签名、未公证，首次打开会被 Gatekeeper 拦下。
xattr -dr com.apple.quarantine "/Applications/DeepSeek Harness.app"

浏览器下载的文件都带隔离标记；用 curl -L -o x.dmg <链接> 下载则不需要这一步。

Windows

  • 下载 windows-x64-unsigned.exe 直接安装。
  • 安装包未签名，SmartScreen 会提示：点「更多信息」→「仍要运行」。

校验与加速

  • 每个 Release 附 SHA256SUMS.txt，用 shasum -a 256 -c SHA256SUMS.txt 校验。
  • 「镜像加速」只是把下载链接改写到第三方 gh-proxy 前缀，文件本身与官方一致；请以 SHA-256 为准。
